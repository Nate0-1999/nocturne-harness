# M3SL real-owner visual verification

These are packaged-app captures against the configured live Palace and an
ordinary zero-provider Symphony launch in a disposable owner home. They are not
fixture-server evidence.

- `real-owner-torrent-constellation.jpg` — TORRENT × CONSTELLATION × CREATURE:
  123 recorded revision events, 3 active memory bodies, 12 historical duplicate
  families, truthful zero active filaments, and the scorer readout. Every legend
  names its underlying Palace field.
- `real-owner-annotated-sheet.jpg` — GOLD LINES annotated field sheet: one
  signed live packet projected into packet/dependency/state/rule grammar, with
  the complete stable packet identity visible.
- `owner-trace.json` — the counts read from the same owner-app pass and its
  explicit zero-write/provider boundary.
- `emulation-bounds.json` and `check_emulation.py` — pinned visual-character
  checks for the dark luminous instrument and the bright analytical sheet.

The owner reference screenshots remain private browser material and are not
redistributed here. The comparison basis is the gate-extracted reference sheet
in `garden/notes/visual-references.md`; the source references and these captures
were auditioned side by side during implementation. The bounds preserve the
translated properties rather than pretending pixel identity between different
content.

Run the image check with:

```sh
python3 verification/m3sl/check_emulation.py
```

`ffmpeg` and `ffprobe` are the only runtime dependencies for that check.
